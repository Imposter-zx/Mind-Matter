# MIND//MATTER — Interactive Philosophy & Consciousness Experience

> *"What if consciousness isn't something the universe created... but something the universe has always had?"*

**MIND//MATTER** is a production-grade, interactive digital philosophy laboratory exploring **Panpsychism, Physicalism, Emergentism, Artificial Intelligence, Personal Identity, and the Hard Problem of Consciousness**.

Built with an Apple-level minimalist, cinematic dark sci-fi aesthetic, the experience allows visitors to experiment with 3D simulations, test their metaphysical intuitions against classic thought experiments, and generate a personal philosophical consciousness profile.

---

## 🌌 Core Philosophy & Intellectual Neutrality

MIND//MATTER remains strictly **intellectually neutral**:
- **Panpsychism is NOT presented as proven scientific fact**.
- Clear visual badges and Stanford Encyclopedia of Philosophy (SEP) references distinguish between:
  - 🟢 **Established Scientific Facts** (e.g. neurobiology, synaptic transmission)
  - 🔵 **Scientific Hypotheses** (e.g. Integrated Information Theory, Global Workspace)
  - 🟣 **Philosophical Hypotheses** (e.g. Constitutive Panpsychism, Physicalism)
  - 🟡 **Thought Experiments** (e.g. Philosophical Zombie, Chinese Room)
  - 🔴 **Speculative Metaphysics** (e.g. Cosmopsychism)
- The site encourages visitors to think and inquire rather than prescribing dogmatic conclusions.

---

## ⚡ Key Features & Interactive Modules

1. **Reactive 3D Cosmic Field (Hero)**: Full-screen interactive particle universe responding smoothly to cursor position, scroll dynamics, and hardware tier.
2. **Where Does Consciousness Begin?**: 7-level interactive progression (Human $\downarrow$ Animal $\downarrow$ Cell $\downarrow$ Molecule $\downarrow$ Atom $\downarrow$ Particle $\downarrow$ ?) with empirical vs philosophical explanatory gaps.
3. **Panpsychism vs. Physicalism Flow Visualizer**: Comparative animated architecture contrasting emergent matter vs. constitutive proto-experience.
4. **Interactive Consciousness Scale**: 9-level deep zoom/inspection visualizer from the Observable Universe down to Fundamental Quantum Particles.
5. **The Combination Problem (3D Simulation)**: Real-time particle aggregation simulation exploring how trillions of micro-experiences could form one macro-subject, paired with three candidate solutions (Emergence, Combination, Holism).
6. **Synthetic AI Consciousness Lab**: 3D synaptic network sandbox with simulated AI dialogue, exploring the Turing dilemma, subjective qualia vs. algorithmic imitation.
7. **Thought Experiments Laboratory**: Interactive simulations of:
   - *The Philosophical Zombie* (David Chalmers)
   - *The Chinese Room* (John Searle)
   - *The Ship of Theseus* (Plutarch / Hobbes)
   - *The Brain in a Vat* (Hilary Putnam)
   - *The Digital Mind Copy & Teletransporter* (Derek Parfit)
8. **Cosmic Topology & Complexity Slider**: 3D galaxy network exploring whether structural complexity creates consciousness, reveals it, or changes matter's behavior.
9. **Cosmopsychism Exploration**: Macro-conscious universe and the "Decombination Problem."
10. **Personal Philosophy Profile**: 10 calibrated Likert questions generating an interactive 4-axis profile (Physicalism vs. Panpsychism, Emergence vs. Fundamental, Biological vs. Synthetic, Reductionism vs. Holism) with copyable summaries.
11. **Procedural Web Audio API Synthesizer**: Deep space ambient harmonic drone and interactive resonant chimes (zero external audio files required, Audio OFF by default, persistent preference).
12. **Philosophical Glossary & Academic References**: Comprehensive modals linking directly to peer-reviewed literature and the Stanford Encyclopedia of Philosophy.

## 🛠️ Technology Stack

- **Framework**: React 18+ (TypeScript)
- **Bundler**: Vite
- **Styling**: Tailwind CSS
- **3D Graphics & Canvas**: Three.js, React Three Fiber (`@react-three/fiber`), Drei (`@react-three/drei`)
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Sound**: Web Audio API (Procedural multi-oscillator synthesizer)
- **Effects**: Canvas Confetti

## 🚀 Getting Started

### Prerequisites
- Node.js (v18.0.0 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/your-username/mind-matter.git
cd mind-matter

# Install dependencies
npm install

# Start local development server
npm run dev
```

Visit `http://localhost:3000` to explore the application.

---

## 📦 Production Build

```bash
# Compile TypeScript and build production bundle
npm run build

# Preview production build locally
npm run preview
```

The output will be placed in the `dist/` directory, optimized with code-splitting and asset compression.

---

## 🌐 GitHub Pages Deployment

The repository includes a GitHub Actions automated deployment workflow in `.github/workflows/deploy.yml`.

To deploy:
1. Push your code to the `main` branch on GitHub.
2. In your repository settings:
   - Go to **Settings** $\rightarrow$ **Pages**.
   - Set **Source** to **GitHub Actions**.
3. The workflow will automatically build and publish the website.
